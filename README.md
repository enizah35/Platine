# Platine

Bot Discord de musique pour un groupe d'amis : lecture sans coupure, le bon titre du premier coup,
playlists de serveur gratuites, lecture auto dans le même style.

Usage **privé uniquement** (voir `docs/adr`). Vision et plan : dépôt `enizah35/workflow-ia`, dossier `docs/discord-music/`.

## Démarrer (dev)

```bash
corepack enable
pnpm install
pnpm lint && pnpm typecheck && pnpm test
```

Mise en place complète sous Windows : `docs/setup-windows.md`.
